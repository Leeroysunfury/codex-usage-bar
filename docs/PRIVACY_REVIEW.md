## 代码检查

- 未发现硬编码 API Key、GitHub Token、真实密码、JWT、私钥、个人邮箱或开发者用户目录。
- 网络操作限于启动 Codex 查询后台并调用初始化与 `account/rateLimits/read`；不发送聊天内容、模型生成请求或额度重置请求。
- 本地日志读取用于 Token、缓存和对话速率；对话标题可读入内存并显示在本机菜单/提示中。状态文件包含会话 ID，应视为私人文件。
- 代理参数来自当前进程环境、系统设置或 Codex 进程参数，日志仅保留不含认证的端点；程序没有写死实际代理配置。
- 源码自测中的 `sample:secret` 是虚构代理认证，用来检验诊断是否去掉用户名和密码，不是真实凭据。环回 IP 与测试端口同样是测试输入。
- 旧命名 `HP.CodexUsageBar` 仅是 Windows 本地单实例锁标签，不是主机账号、密码或网络地址；保留它以避免与已安装版本同时运行。
- 注册表键、官方文档 URL 不是磁盘绝对路径。系统运行时通过环境与程序位置生成的路径也不等于写死的开发者路径。

`scripts/check-publication.ps1` 对文本和二进制扫描常见密钥、JWT、私钥、邮箱、写死的磁盘路径，并检查误入的运行文件；输出只列位置和类别，不回显秘密。静态模式检查无法证明不存在任何形式的敏感内容，因此还人工检查了数据读写、测试内容与演示图片来源。
